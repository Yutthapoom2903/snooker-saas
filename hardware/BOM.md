# BOM — อุปกรณ์ต้นแบบ 1 โต๊ะ (+ ESP32 สำรอง 1 ตัว)

รายการนี้สำหรับ **prototype 1 โต๊ะ** ใช้ค้นใน Shopee / Lazada หรือร้านในไทย
(Arduitronics, Cybertice, ArduinoAll, Gravitechthai ฯลฯ) ราคาเป็น **ประมาณการ (THB, ปี 2026)**
ร้านต่างกันได้ ±30% ค่าส่งไม่รวม

> คำค้นที่ใส่ไว้ใน `code` คือคำที่ใช้ search ได้ตรงที่สุด เวลาสั่งให้เทียบสเปกในวงเล็บด้วย

## 3. Power budget (สำคัญ)

| ภาระ | ปกติ (ความสว่าง 4/15, ตัวอักษรติด ~30%) | กรณีแย่สุด |
|---|---|---|
| จอ MAX7219 8x32 × 2 (8 บล็อก 8x8) | ~0.25 A | **~2.6 A** (ทุกดวงติด ความสว่าง 15/15) |
| ESP32 (WiFi) | ~0.08 A เฉลี่ย | ~0.5 A peak ตอนส่ง WiFi |
| Relay coil | 0.07–0.08 A | 0.08 A |
| Buzzer | 0.03 A | 0.03 A |
| **รวม** | **~0.45 A** | **~3.2 A** |

ข้อสรุป:
- **ใช้ adapter 5V 3A** เลี้ยงทุกอย่าง (จอ, รีเลย์, ESP32 ทางขา `VIN`) — GND ทุกตัวต่อร่วมกัน
- **ห้ามเลี้ยงจอจากขา 3V3 ของ ESP32** (regulator บนบอร์ดจ่ายได้ราว 0.5–0.8 A และ MAX7219 ต้องการ 5V)
  และ **ห้ามเลี้ยงจอจาก USB อย่างเดียว** (พอร์ต USB คอมจ่ายได้ ~0.5 A → ไฟตก ESP32 รีเซ็ตเอง / WiFi หลุด)
- Firmware **จำกัดความสว่าง** ไว้ที่ `TIMER_INTENSITY = 4`, `SCORE_INTENSITY = 4` และเพดาน `MATRIX_INTENSITY_MAX = 8`
  (ใน `firmware/src/common/config.h`) — ในร้านในร่ม 3–5 สว่างพอ
- ใส่ **1000µF** คร่อม VCC/GND ใกล้ขั้วไฟของแต่ละจอ
- สายไฟ 5V ไปจอใช้เส้นใหญ่พอ (22AWG ขึ้นไป) ไม่ใช้สาย dupont เส้นเล็กยาวๆ สำหรับไฟเลี้ยง

## 4. เรื่อง 3.3V logic ขับ MAX7219

ESP32 ส่งสัญญาณ 3.3V แต่ MAX7219 (เลี้ยง 5V) สเปกต้องการ logic high ≥ 3.5V
**ในทางปฏิบัติส่วนใหญ่ใช้ได้** กับสายสั้น (< 20–30 cm) อาการถ้าไม่ผ่าน: จอค้าง, ตัวอักษรเพี้ยน/สุ่ม, บางบล็อกไม่ติด

ทางแก้ตามลำดับ:
1. ทำสาย DIN/CLK/CS ให้สั้น และเดิน GND คู่ไปด้วย
2. ใส่ **74AHCT125** (เลี้ยง 5V) คั่น 3 เส้น DIN, CLK, CS (ทั้งสองจอ) — ดู `WIRING.md`
3. (ทางเลือกชั่วคราว) เลี้ยงจอที่ ~4.3V เช่นผ่านไดโอด 1N5822 จาก 5V — ทำให้ threshold ต่ำลง แต่จอหรี่ลงเล็กน้อย

## 5. เรื่อง Relay module กับ 3.3V

โมดูลรีเลย์ 5V ส่วนใหญ่เป็น **low-level trigger** (IN = LOW → รีเลย์ติด)
ถ้า ESP32 ส่ง HIGH แค่ 3.3V บางโมดูล **ไม่ยอมดับ** (opto ยังมีกระแสไหลเล็กน้อย) วิธีแก้:
- ซื้อรุ่นที่มี **jumper H/L** แล้วตั้งเป็น **H (high-level trigger)** → แก้ `RELAY_ACTIVE_LOW false` ใน `config.h`
- หรือรุ่นที่มี jumper `JD-VCC`: ถอด jumper ออก, ต่อขา `VCC` ฝั่ง opto เข้า **3V3** ของ ESP32, ต่อ `JD-VCC` เข้า **5V**, GND ร่วม → IN ทำงานที่ 3.3V สมบูรณ์
- ค่าเริ่มต้นใน firmware คือ `RELAY_ACTIVE_LOW true` (โมดูลทั่วไป)

## 6. ⚠ คำเตือนความปลอดภัย — ไฟบ้าน 220V

> **การต่อรีเลย์เข้ากับไฟบ้าน 220V (ไฟโต๊ะสนุ้ก) ต้องให้ช่างไฟฟ้าที่มีใบอนุญาตเป็นผู้ต่อเท่านั้น**
>
> - ทดสอบทุกอย่างด้วย **ไฟ 12V (LED strip / หลอด 12V)** ก่อนเสมอ
> - โมดูลรีเลย์ราคาถูกบน PCB เปลือย **ไม่มีฉนวนกันสัมผัส** — ห้ามจับขณะต่อไฟ 220V, ต้องอยู่ในกล่องปิดมิดชิด
> - รีเลย์ 10A ใช้กับไฟโต๊ะ LED ได้ แต่หลอดฟลูออเรสเซนต์/บัลลาสต์มีกระแสกระชาก — ให้ช่างพิจารณาใช้
>   **contactor หรือ SSR** ที่เหมาะสม และใส่ **เบรกเกอร์/ฟิวส์** ทุกครั้ง
> - ต้องมีสวิตช์มือ (bypass) เปิดไฟโต๊ะได้ แม้ ESP32/ระบบเสีย
> - แยกสายไฟ 220V ออกจากสายสัญญาณ 3.3V/5V (คนละฝั่งกล่อง)

## 7. Checklist ตรวจของตอนได้รับ (ก่อนประกอบ)

- [ ] ESP32: เสียบ USB แล้ว Windows เห็น COM port (ถ้าไม่เห็น ติดตั้ง driver **CP210x** หรือ **CH340** ตามชิปบนบอร์ด) — ไฟ LED power ติด
- [ ] ESP32: ตรวจว่าเป็น **WROOM-32** (ดูบนฝาเหล็ก) ไม่ใช่ WROVER / ESP32-S3 / C3
- [ ] จอ MAX7219: ไม่มีขาหัก, ชิป MAX7219 4 ตัวอยู่ครบ, มีหัว DIN (ฝั่ง input) และ DOUT ชัดเจน
- [ ] ปุ่ม: วัด continuity — กดแล้ว "ติ๊ด" ปล่อยแล้วเงียบ (NO, ไม่ล็อค)
- [ ] รีเลย์: ดูว่ามี jumper H/L หรือ JD-VCC ไหม (จะได้ตั้ง `RELAY_ACTIVE_LOW` ถูก)
- [ ] Adapter: วัดไฟขาออกได้ ~5.0–5.2V และขั้วกลางเป็น + (ตามที่ระบุบน adapter)
- [ ] จากนั้น flash `hwtest` แล้วไล่ทีละขั้นตาม `README.md`
